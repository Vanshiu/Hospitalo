# 🏥 Hospitalo

Hospitalo is a full-stack hospital discovery platform that helps users find nearby hospitals based on their location. It provides an interactive map, hospital details, filtering options, secure authentication, and a review system to help users make informed healthcare decisions.

## 🚀 Features

- Location-based hospital discovery
- Interactive Mapbox integration
- Search and filter hospitals
- User authentication and authorization
- Hospital reviews and ratings
- Responsive user interface

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- EJS
- Mapbox API
- Passport.js
- HTML
- CSS
- JavaScript

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Vanshiu/Hospitalo.git
```

Move to the project folder

```bash
cd Hospitalo
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm start
```
